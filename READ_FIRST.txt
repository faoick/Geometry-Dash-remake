Dash Rebuild 0.1.1 — Windows x64

1. Полностью распакуй ZIP в обычную папку.
2. Открой DashRebuild.exe. Установка Python не нужна.
3. Сохраняй рядом папки _internal и mods. Один exe отдельно не переносится.

На компьютере должна быть установлена Geometry Dash: её уровни, текстуры и
музыка читаются локально. В архиве этих ресурсов нет.

Если папка игры не находится автоматически, создай рядом с exe файл
resources-path.txt. Вставь в него одну строку: полный путь к папке Geometry Dash
или к её папке Resources. Например:
D:\SteamLibrary\steamapps\common\Geometry Dash

Если запуск не удаётся:
- попробуй Start.cmd — он также сохраняет bootstrap.log;
- пришли user_data\launch.log, user_data\crash.log и user_data\bootstrap.log,
  если они создались;
- если папка недоступна для записи, журнал будет в
  %LOCALAPPDATA%\DashRebuild\user_data либо %TEMP%\DashRebuild\user_data;
- окно ошибки показывает текст причины и путь к журналу.

Space / ЛКМ — прыжок или полёт. Esc — пауза. R — заново.
H — хитбоксы. N — без смерти. T — замедление. M — звук.

Свои моды — файлы Python в папке mods. Изменяемый исходный код — в source.
Это экспериментальный независимый движок; точность 1:1 с оригиналом не заявлена.
